# 🦅 ÁGUILA - Lenguaje de Programación

Instalador oficial del lenguaje de programación **ÁGUILA** para Node.js.

> **"Lo mismo que Python, pero más veloz y en Español."**

📚 **[LEER LA DOCUMENTACIÓN OFICIAL AQUÍ](https://aguila.compilandocode.com/biblioteca)**  
Visita nuestra página web oficial para aprender la lógica que mueve al mundo, con guías interactivas, ejemplos y la referencia completa de la API.

## 🚀 Instalación

```bash
npm install -g aguila-lang
```

Esto descargará automáticamente el binario optimizado para tu sistema operativo (Windows, macOS o Linux).

## 💻 Uso

Una vez instalado, puedes usar el comando `aguila` desde tu terminal:

```bash
# Iniciar REPL
aguila

# Ejecutar un script
aguila ejecutar mi_script.ag

# Compilar a JavaScript
aguila compilar mi_script.ag

# Ver ayuda
aguila --ayuda
```

## 📦 Qué incluye

Este paquete instala el binario nativo de Águila (escrito en Rust), que incluye:
- Intérprete de alto rendimiento
- Compilador a JavaScript
- Analizador estático
- REPL interactivo
